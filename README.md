# 🌍 全球手机号码估价工具 (PhoneNumberValueEstimator)

基于 **Win32 SDK** 纯原生 API 开发的轻量级全球手机号码验证与价值评估工具。程序内置了全语系核心国家/地区的真实移动号段白名单数据库，并提供极佳的纯键盘流交互体验。

本项目由 **Gemini** 协作构建。

---

## ✨ 核心功能亮点

* **🚫 真实号段级硬核拦截**：不只是验证号码长度！程序精细化匹配各国真实的移动手机开头（例如：中国严格限制 `13-19` 开头，输入 `123` 或非数字将在按键瞬间被拦截并触发系统警报，无法输入）。
* **📋 粘贴文本强力审计**：支持从剪贴板任意复制文本，程序会自动剔除非数字字符，并从首个非法号段位置执行**硬截断**，杜绝伪造号码。
* **📉 “零起步”动态估价算法**：彻底剥离传统保底分机制。普通乱序号直接归零（￥0/$0），只有当号码真正触发 **3连号以上（AAA）**、**长顺子（1234+）** 或 **特定尾数规律（AABB/ABAB）** 时才产生溢价。
* **💱 本地化货币符号展示**：估价结果不再单一显示美元，而是根据所选国家/地区自动转换为当地货币格式（如 `￥`、`$`、`£`、`€`、`₩`、`¥`），并结合当地经济权重和汇率进行大面额校准。
* **⌨️ 极客级键盘流交互**：
    * `Enter (回车键)`：立即提交验证并计算估价。
    * `Esc (退出键)`：一键清空输入框并重置焦点，双手无需离开主键区。
    * `Ctrl + A`：支持全选输入框内容。

## 🚀 快速开始

### 1. 开发环境要求
* **操作系统**：Windows 7 或更高版本
* **编译器**：支持 C++11 或更高标准的编译器（如 MSVC / MinGW）
* **依赖库**：仅依赖 Windows 原生 API（`user32.lib`, `gdi32.lib`, `comctl32.lib`），无任何第三方庞大库依赖，编译产物极小。

### 2. 编译与运行 (以 MSVC 命令行为例)
```bash
# 编译源代码
cl.exe /EHsc WinMain.cpp user32.lib gdi32.lib comctl32.lib

# 运行程序
WinMain.exe

```

## 🛠️ 技术内幕 (Technical Architecture)

* **UI 架构**：纯原生 Win32 窗口过程（`WindowProc`），无任何多余的运行时开销。
* **输入框子类化 (Subclassing)**：通过 `SetWindowLongPtr` 接管了 `EDIT` 控件的 `WM_CHAR` 与 `WM_PASTE` 消息，在字符真正进入输入框之前进行前缀白名单树状逻辑过滤。
* **内存优化**：利用标准库 `std::vector` 与 `std::wstring` 构建动态国家/地区上下文，避免了硬编码造成的内存抖动。
